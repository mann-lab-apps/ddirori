**설명**

건반이 들리는 첫 마디는 귀로 듣고, 다음 마디는 손뼉으로 대답해 보세요. 둘째 박에서 손은 쉬고 발끝은 박을 짚어요. 레슨에서는 학생이 문제를 내고 선생님이 따라 해도 좋아요.

## 무엇을 확인하는가

| 기간과 출처 | 관찰할 값 | 해석 |

첫 주 전체 실험은 **11월 23~29일, 12월 2일부터 판정**한다. 쇼츠 게시가 늦어지면 게시 시각을 기록하고, 채널 비교에는 게시 다음 날부터 온전한 7일을 별도로 잡는다. 종료 3일 뒤에 같은 명령의 날짜를 바꿔 읽는다. 게시 전 기간을 실험 노출 기간에 포함하지 않는다.

```sh
# 이 프로필 링크를 사용한 세션
uv run scripts/lesson-ga4-report.py --property 563700721 --start 2026-11-23 --end 2026-11-29 \
  --channel 'youtube / organic_social' --campaign free_lessons_echo_01

# 같은 기간 전체 수업, 기존 주간 판정
uv run scripts/lesson-ga4-report.py --property 563700721 --start 2026-11-23 --end 2026-11-29
```

판정할 때는 다음 순서로 읽는다.

- 게시 기록이나 Studio 지표가 없으면 노출은 미확인으로 남긴다.
- 참여 조회가 있어도 GA4 도달 행이 비면 프로필 링크의 표시 위치와 주소부터 확인한다. 빈 응답을 방문자 0명으로 기록하지 않는다.
- 도달 행이 있고 재생이 명시적으로 0이면 모바일에서 링크를 연 뒤 음원을 재생하는 동선을 살핀다. 작은 표본에서는 전환율과 함께 실제 인원도 적는다.
- 신규 재생이 관찰되면 같은 조건으로 다음 주제 한 편을 시험한다. 채널을 통한 신규 재생은 기존 정의대로 교사용 수업의 첫 실제 재생이며, 페이지에서 다른 활동을 먼저 들은 경우도 포함한다.

## 재사용할 목표 모드 프롬프트

> 실제 교사용 음원에서 초급 피아노 선생님이 20초 안에 직접 해볼 수 있는 리듬 문제 한 개를 고른다. 기존 띠로리 글꼴·색·캐릭터를 사용해 듣기, 대답할 시간, 정답, 같은 무료 수업으로 이어지는 프로필 안내가 있는 세로 MP4를 제작한다. 완성 영상에서 박자와 쉼, 화면 자막을 검증하고 프로필 링크가 모바일에서 해당 음원의 재생 위치를 여는지 확인한다. 게시용 제목과 설명, 전용 캠페인 주소, 읽기 전용 GA4 기준선과 게시 후 판정 명령을 남긴다. 외부 게시 상태와 실제 관측 결과는 각각 근거가 생겼을 때 기록한다.

이번 영상은 웹의 4주차 음원을 사용한다. 90 BPM에서 준비 네 박, 건반 한 마디, 응답 한 마디, 정답과 응답을 차례로 들려주고 마지막에 수업을 안내한다. 영상은 저장소 루트에서 `uv run scripts/render-echo-short.py`로 다시 만들 수 있다. 수업 태그까지 검증하는 명령은 [GA4 운영 문서](../lesson-ga4.md)에 있다.
